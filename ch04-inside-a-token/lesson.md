# 4. Inside a Token

A token is a string, but it isn't a random one. Most tokens you'll meet are JSON Web Tokens, which are built from three parts joined by dots. Each part is a readable structure, and the way they fit together is the reason a token can be checked at all. This chapter takes a token apart, shows how each part is encoded, and explains what decoding does and what it doesn't.

The chapter has two reading steps, a sample step, two homework items, and a summary with three quizzes.
