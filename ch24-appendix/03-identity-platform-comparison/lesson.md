# Identity Platform Comparison

The comparison of terms for Microsoft Entra ID, Okta, AWS, Google Cloud, and Keycloak is in Chapter 12, in the comparison table. It is kept there, next to the reading that explains how to use it, so that the two stay together.

Use the table as a map. Find the concept you need, such as the token issuer or the workload identity, and then confirm each detail against the current documentation for the platform and edition you use. Platforms rename features and change defaults, so a row in the table is a starting point, not the final answer.

If you are choosing a platform, Chapter 12's homework on mapping a scenario is the best practice for comparing them against a real use case.
