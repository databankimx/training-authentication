# 3. API Keys

An API key is the simplest credential most APIs offer. You get a long string, you send it with each request, and the API uses it to find the account or project it belongs to. Because keys are so simple, they're used everywhere, and they're handled carelessly almost as often. This chapter explains what a key identifies, what it doesn't, and where it goes in a request.

The chapter has two reading steps, a sample step, two homework items, and a summary with three quizzes.
