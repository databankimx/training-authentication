# 23. Capstone

This chapter brings the tutorial together. You'll see a client obtain a token, an API check that token, and the two refusals that matter most, all in one program. The sample has no network access, so its identity provider is simulated in the same file.

The chapter has a reading step, a capstone sample, a second reading step about moving to a real identity provider, a code homework item, a written homework item, and a summary with three quizzes. The second reading step has an optional part for readers who have a test account of their own. It has no check, and it's optional.
