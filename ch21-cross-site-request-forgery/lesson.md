# 21. Cross-Site Request Forgery

Browsers send cookies automatically with every request to the site that set them, including requests that a page on another site caused. That's convenient for a signed-in user, and it's the basis of cross-site request forgery: a page the person happens to visit makes their browser send a change to a site where they are signed in, and the site acts on it, because the session cookie came along.

The chapter has a reading step, a sample step, a second reading step, a code homework item, a written homework item, and a summary with three quizzes.
