# 10. The Device Code Flow

Some scripts run on machines that have no browser: a server in a rack, a container, or a small device with a screen and nothing else. They still need a token that belongs to a person, and a person has to approve it. The device code flow solves that. The device shows a short code and a web address. A person opens the address on a phone or laptop, signs in, and enters the code. Meanwhile the device waits for the answer.

The chapter has a reading step, a sample step, a code homework item, a written homework item, and a summary with three quizzes.
